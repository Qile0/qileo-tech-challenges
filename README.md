## 🎯 Challenges

**flutter**: Transaction Widget — Widget de liste de transactions fintech avec gestion des états de chargement, d'erreur, de filtrage et d'état vide.

## 🧪 Tests à faire passer

### flutter — Transaction Widget
1. `shows_loading_indicator_while_fetching()` — Affiche un loader pendant le chargement
2. `displays_transactions_after_load()` — Affiche la liste après chargement
3. `shows_error_message_on_failure()` — Affiche une erreur si le fetch échoue
4. `filters_transactions_by_status()` — Filtre par statut
5. `shows_empty_state_when_no_transactions()` — Affiche un état vide si liste vide
